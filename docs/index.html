Instálala en tu iPhone

Para recibir avisos en iOS la app tiene que estar en la pantalla de inicio:

  1. Abre esta página en Safari.
  2. Pulsa Compartir (el cuadrado con la flecha).
  3. Elige Añadir a pantalla de inicio.
  4. Abre la app desde el icono nuevo y vuelve aquí.

Activa los avisos para enterarte en cuanto haya stock.

Último paso: copia este código y pégalo en GitHub como secreto PUSH_SUBSCRIPTIONS (ver README).
